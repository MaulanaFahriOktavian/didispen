# Role & Permission DIDISPEN

## 1. ADMIN

Login menggunakan Email dan Password

Hak Akses:

- Dashboard
- Kelola User
- Kelola Role & Permission
- Kelola Data Guru
- Kelola Data Siswa
- Kelola Jurusan
- Kelola Kelas
- Kelola Kategori Dispensasi
- Kelola Tahun Ajaran
- Melihat Semua Pengajuan
- Approval (Opsional)
- Melihat Laporan
- Dashboard Statistik
- Audit Log
- Pengaturan Sistem

---

## 2. GURU PIKET

Login menggunakan NIP dan Password

Hak Akses:

- Dashboard
- Melihat Pengajuan
- Approval Dispensasi
- Menolak Dispensasi
- Memberikan Catatan
- Melihat Riwayat
- Melihat Statistik

---

## 3. SISWA

Login menggunakan NIS dan Tanggal Lahir

Hak Akses:

- Dashboard
- Membuat Pengajuan Dispensasi
- Upload Dokumen Pendukung
- Melihat Status Pengajuan
- Melihat Riwayat Dispensasi
- Download Surat Dispensasi (PDF)
- Menampilkan QR Code Dispensasi

---

## 4. SATPAM

Hak Akses:

- Dashboard Satpam
- Scan QR Code Dispensasi
- Melihat Detail Dispensasi
- Validasi Siswa Keluar
- Validasi Siswa Kembali
- Mencatat Jam Keluar
- Mencatat Jam Masuk
- Menolak QR Code Tidak Valid
- Melihat Riwayat Keluar Masuk Hari Ini
